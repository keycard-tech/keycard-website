# Name your Keycard

Name your Keycard to identify it easily. Shell displays the name on the top line. Software wallets can also show the name.

Default name: the [fingerprint](./verify-your-keycards-seed-and-addresses#check-the-seed-fingerprint) of your seed

A fingerprint is a short code made from your seed. Many wallets show the same code for the same seed. This makes it a common way to recognize one seed across different wallets.

Change it: **Settings** > **Keycard** > **Rename**
