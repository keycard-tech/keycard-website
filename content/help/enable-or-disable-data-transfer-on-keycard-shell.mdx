# Enable or disable data transfer on Keycard Shell

Keycard Shell can charge over USB-C at any time, but USB data transfer is optional. Disable USB data transfer to keep the device air-gapped between updates or when you do not need USB wallet connections.

## Enable or disable USB data transfer

1. Insert your Keycard into Keycard Shell to power it on.
1. Enter your Keycard PIN.
1. Go to **Settings** > **Device** > **USB data**.
1. Select **On** to enable data transfer or **Off** to disable it.
1. Press **OK** to confirm.

<Admonition type="note">
  When USB data transfer is off, Keycard Shell still charges over USB-C, but it ignores USB data connections. Turn it back on before using WebHID updates or USB-based wallet connections.
</Admonition>
