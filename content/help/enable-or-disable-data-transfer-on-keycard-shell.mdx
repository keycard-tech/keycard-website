# Enable or disable data transfer on Keycard Shell

Keycard Shell can charge over USB-C at any time, but USB data transfer is optional. YOu can disable USB data transfer at Shell level to make sure no data access to your Shell is possible when it's charging through a USB-C cable plugged on a computer or an unknown charger.

## Enable or disable USB data transfer

1. Insert your Keycard into Keycard Shell to power it on.
2. Enter your Keycard PIN.
3. Go to **Settings** > **Device** > **USB data**.
4. Select **On** to enable data transfer or **Off** to disable it.
5. Press **OK** to confirm.

<Admonition type="note">
  When USB data transfer is off, Keycard Shell still charges over USB-C, but it ignores USB data connections. Turn it back on before performing web based firmware and database upgrades, or if you want to use Shell with software wallets that implement USB-based wallet connections.
</Admonition>
