# Connect Keycard Shell to a software wallet

![Header image showing Keycard Shell alongside a software wallet on both a mobile phone and a computer.](/assets/docs/connect-keycard-shell-to-a-wallet-app-header.png)

Keycard and Keycard Shell must work together with a software wallet that supports QR signing. After [setting up your Keycard](./set-up-your-keycard-with-keycard-shell), you need to connect your Keycard Shell to a [supported software wallet](https://keycard.tech/en/wallets). 

<Admonition type="note">
    Currently, Keycard Shell doesn't always appear on software wallet's list of supported hardware wallets, but you can still connect it to a [supported software wallet](https://keycard.tech/en/wallets) by selecting the **QR-based** (for example, MetaMask) or **Keystone** (for example, Rabby and Nunchuk) option.
</Admonition>

## What to expect

- The software wallet is an interface to manage your crypto assets. The private keys remain on your Keycard, and the software wallet has no access to them.
- You can connect your Keycard Shell to one or multiple software wallets.
- You can [disconnect Keycard Shell from a software wallet](./disconnect-keycard-shell-from-a-wallet-app) at any time.
- You can use the software wallet on your phone, computer or browser, depending on what the app supports.

## About software wallets types

Before connecting to a software wallet, you must select the type of software wallet you want to connect to in Keycard Shell. Here are the options:

- **Ethereum**: For software wallets that support Ethereum and EVM-compatible networks, such as MetaMask, Rabby or imToken.
- **Bitcoin**: For software wallets that support Bitcoin, such as Sparrow, Specter or Nunchuk.
- **Bitcoin multisig**: Select this option to use Bitcoin multisig with the software wallet .
- **Bitcoin testnet**: Select this option to use Bitcoin testnet with the software wallet.
- **Multiple blockchains**: For software wallets that support multiple blockchains, such as Bitget.

<Admonition type="note">
    **Bitcoin multisig** and **Bitcoin testnet** options are for advanced users.
</Admonition>

## Connect Keycard Shell to a software wallet

In this process, you use your software wallet to scan a QR code displayed on your Keycard Shell.

<Admonition type="tip">
    Follow the detailed steps to connect Keycard Shell to [MetaMask](./connect-keycard-shell-to-metamask) or [BlueWallet](./connect-keycard-shell-to-bluewallet) if you use these software wallets.
</Admonition>

### Step 1: Prepare the software wallet

Some software wallets like Metamask, require you to create a new wallet account or import your existing wallet before connecting Keycard Shell even if you if you don't plan to use it. This wallet is separate from your Keycard and Keycard Shell.

1. Open the software wallet you want to connect to on your computer or smartphone.
1. If required, create a new wallet account or import an existing one using your recovery phrase. 
1. In your software wallet, choose the option for connecting a hardware wallet.
1. Select **QR-based** or **Keystone** depending on which one is available. 
1. Continue with the instructions in your software wallet to open your computer or smartphone camera.

### Step 2: Prepare your Keycard Shell

1. Insert your Keycard into Keycard Shell to power it on. 
1. Enter your Keycard PIN.
1. Select **Connect software wallet**.
1. Press **OK**.
1. Select **Ethereum**, **Bitcoin**, **Bitcoin Multisig**, **Bitcoin Testnet** or **Bitget**.

### Step 3: Scan the QR code

1. Scan the QR code displayed on the Keycard Shell screen using your computer or smartphone camera.
1. In your software wallet, select the accounts you want to use in the software wallet.
1. In your software wallet, confirm to connect the selected accounts.

<Admonition type="note">
    Steps may vary depending on your software wallet. Refer to your wallet's documentation for exact instructions on connecting a hardware wallet.
</Admonition>
