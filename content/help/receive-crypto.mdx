# Receive crypto

View your Keycard's public addresses on Shell.

1. Insert Keycard and enter your PIN.
2. Go to **Addresses** > **Ethereum** or **Addresses** > **Bitcoin**.

Shell displays the public addresses of your Keycard, and indicates the index `<n>` on the bottom of the screen:
- Ethereum: BIP44 public address (and QR code) on path m/44'/60'/0'/0/`<n>`
- Bitcoin: BIP84 native SegWit address (and QR code) on path m/84'/0'/0'/0/`<n>`

<Admonition type="note">
These are the addresses that Shell can show you on its screen. However, Shell can actually derive and sign using a variety of other derivation paths, which can be set in your software wallet. If you're an advanced user and want more information, see the article on [other derivation path support](./other-derivation-path-support).
</Admonition>
