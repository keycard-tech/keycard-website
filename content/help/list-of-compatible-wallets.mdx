# List of compatible wallets

Keycard and Shell can be used with a [large number](/wallets) of software wallets. 

At launch Keycard and Shell support ecdsa secp256k1 signing and thus work with Ethereum, EVM compatible chains, and Bitcoin. We are actively working on supporting more cryptography primitives and more blockchains.
