# Disconnect from software wallet

When you want to use Shell with a [software wallet](/wallets), you usually first need to [connect](./connect-keycard-shell-to-a-software-wallet) Shell with this software wallet. If you wish to disconnect Shell from this software wallet, this must be done on the software wallet side. Shell does not maintain any kind of link with the software wallets.
