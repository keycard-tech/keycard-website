# Understand the Slip39 wallet backup standard

Slip39 is a standard for creating secure and flexible backups of crypto wallets. With Slip39, users can split their wallet keys into multiple shares, which can be distributed among trusted parties or stored in different locations. This ensures that even if some shares are lost or compromised, the wallet can still be recovered.
