# Supported Wallets

Keycard and Keycard Shell work with various software wallets that connect to the internet, as the hardware wallets are offline.

## Wallets for Keycard

Keycard integrates natively with all Status apps:

[Status mobile](https://status.app/apps#mobile), on iOS and Android - a secure wallet and messenger for Ethereum and other blockchains. Use it standalone via NFC for wallet operations.

[Status desktop](https://status.app/apps#desktop), on Windows, MacOS, and Linux. Connect the Keycard via card reader to your desktop computer.

## Wallets for Keycard Shell

Keycard Shell expands compatibility by adding a camera and display, enabling Keycard to work with wallets that support QR-based interaction ([EIP-4527](https://eips.ethereum.org/EIPS/eip-4527) and [UR](https://github.com/BlockchainCommons/crypto-commons/blob/master/Docs/ur-overview.md)).
