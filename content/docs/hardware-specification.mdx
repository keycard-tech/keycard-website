# Hardware Specification

## Keycard

- **Requirements:** JavaCard 3.0.4+, 10kb NVM, supports AES, ECDSA, SHA-256/512, etc. (see [applet installation](https://keycard.tech/docs/applet_installation)).
- **Interfaces:** NFC, ISO7816.

## Keycard Shell

- **Features:** Camera, display, buttons, Nokia BL-4C battery.
- Find details on [our Github](https://github.com/keycard-tech/keycard-pro/blob/master/hw/elec_/BOM.csv).
- **Purpose:** Enhances Keycard with QR scanning and display for wallet compatibility.
