# Software Integration

## Java SDK

The [Java SDK](https://keycard.tech/docs/sdk) simplifies Keycard integration on desktop (via `javax.smartcardio`) and Android (via NFC). See [installation details](https://keycard.tech/docs/sdk/installation).

## Web3 API Extension

The [Web3 API Extension](https://keycard.tech/docs/web3) supports the Cash applet for signing EIP-712 metatx, compatible with dApps via `keycard_signTypedData(data)`.

## APDU API

The [APDU API](https://keycard.tech/docs/apdu) provides low-level access to Keycard’s secure chip for custom integrations.
