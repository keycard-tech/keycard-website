# Troubleshooting

## Common Issues

### Display Errors

Restart the Shell by removing and reinserting the battery. If issues persist, reinsert the Keycard to reset the connection.

### Device Won’t Turn On

- **Keycard Shell:** Check the Nokia BL-4C battery charge. Replace or recharge if needed.
- **Keycard:** Ensure it’s not a pairing issue—test with Status or Keycard Connect.

### QR Code Not Scanning

Clean the Shell’s camera lens with a microfiber cloth. Adjust lighting to avoid glare. Ensure the QR code is fully in view.
