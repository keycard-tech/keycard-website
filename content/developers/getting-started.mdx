# Getting Started

This guide gets you from a blank card to a working development setup: initializing a Keycard, reinstalling applets for testing, and knowing which card hardware the applet runs on. Keycard ships with pre-installed applets, ready for initialization.

<Admonition type="tip">
  Before integrating, skim [Core Concepts](/developers/core) for the card
  lifecycle and credentials model (PIN, PUK, pairing). Once your card is set
  up, continue with the [Keycard SDK](/developers/sdk) — or the [Keycard
  API](/developers/apdu) if you're implementing the protocol directly.
</Admonition>

## Getting Started with Keycard

To begin, use [Keycard Connect](https://github.com/keycard-tech/keycard-connect) on Android, or any wallet that integrates Keycard directly — currently Status mobile (NFC), Status desktop and Sparrow (USB reader); see the [full list](/wallets).

These apps help initialize your Keycard with a pairing key, PIN, PUK, and BIP39 seed. Follow the in-app prompts to pair your Keycard via NFC.

Keycard connect also provides basic functionality like changing credentials, changing or removing keys and clear pairing slots. The last functionality is especially useful if you are integrating with Keycard and accidentally fill all pairing slots. Using the "Unpair others" button will remove all pairing except the Keycard Connect's one.

### Applet Installation

Keycard applets are pre-installed. In some cases you might want to reset the applet status completely for testing purposes. This is done by reinstalling the applet, which can be accomplished using the [Keycard CLI](https://github.com/keycard-tech/keycard-cli). To use the Keycard CLI, a USB reader is needed to be able to communicate with the card. The repository contains example scripts for applet reinstallation.

### Card Requirements

The Keycard applet can be installed not only on our cards, but on any JavaCard that supports the required cryptographic algorithms — see the up-to-date list in the [status-keycard README](https://github.com/keycard-tech/status-keycard#what-kind-of-smartcards-can-i-use). All allocations, instantiations and checks are performed at installation time, so if installation succeeds, the applet will work fine.

### Verifying Firmware Integrity

After initialization, verify the firmware by checking the applet version via Keycard CLI. Ensure it matches the latest release (e.g., 3.1) on [GitHub](https://github.com/keycard-tech/status-keycard/releases).
