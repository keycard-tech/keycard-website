# FACTORY RESET

* CLA = 0x80
* INS = 0xFD
* P1 = 0xAA
* P2 = 0x55
* Response SW = 0x9000 on success

Resets the card to its uninitialized state. This deletes all stored keys and user data. There is no way to get the information back.

This is one of the three commands that work without a [secure channel](/developers/apdu/opensecurechannel), together with **SELECT** and **OPEN SECURE CHANNEL** — which is what makes it usable on a card whose credentials are unknown or blocked.
