# Keycard SDK (Java)

This is the reference SDK for integrating Keycard into an application. It is a Java library covering the full card protocol — connection, pairing, secure channel, key management and signing — and runs on desktop (via `javax.smartcardio` and a USB reader) and on Android (via the on-board NFC reader). Installable with Gradle or Maven.

Working in another language? Go and Swift SDKs are maintained by the team, and community ports exist for Python, TypeScript, Nim and React Native — see the [ecosystem page](/developers/github-repositories). All of them implement the same [APDU protocol](/developers/apdu) documented in this section's counterpart.
