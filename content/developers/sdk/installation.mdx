# Installation

You can import the SDK in your Gradle or Maven project using [Jitpack.io](https://jitpack.io). If using Gradle, to use
JitPack all you have to do is insert these lines in you `build.gradle` file

```groovy
allprojects {
  repositories {
    maven { url 'https://jitpack.io' }
  }
}
```

Then you must import the correct dependency. On the desktop (a USB reader via `javax.smartcardio`):

```groovy
dependencies {
  implementation 'com.github.keycard-tech.status-keycard-java:desktop:4.0.0'
}
```

On Android, depend on the platform-neutral module and wire the NFC transport yourself:

```groovy
dependencies {
  implementation 'com.github.keycard-tech.status-keycard-java:lib:4.0.0'
}
```

`lib` contains the whole protocol — command sets, secure channel, parsing — and depends on nothing but BouncyCastle. You implement `im.status.keycard.io.CardChannel` over your `IsoDep` connection and pass it to `KeycardCommandSet`.

<Admonition type="caution">
  Version 4.0.0 of the SDK is the first that speaks the applet 4.0 secure
  channel, and it still supports 3.x cards. Earlier 3.x releases cannot talk to a
  4.0 card at all.

  Two things changed alongside the protocol. The JitPack coordinates moved from
  `com.github.status-im.*` to `com.github.keycard-tech.*` when the repository
  moved; the old coordinates only resolve to the old releases. And the packaged
  Android NFC helpers are not part of the 4.0.0 publication, which is why
  Android builds take `lib` — see [Card Connection](/developers/sdk/connection).
</Admonition>
