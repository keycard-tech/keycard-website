# Ecosystem & Repositories

Everything Keycard ships is developed in the open under the [keycard-tech](https://github.com/keycard-tech) GitHub organization. This page maps what exists: the core repositories, the SDKs and the tools.

## Core repositories

<Table>
    <TableHead>
        <TableHeader>Repository</TableHeader>
        <TableHeader>What it is</TableHeader>
    </TableHead>

    <TableContent>
        <TableRow>
            <TableCell>[status-keycard](https://github.com/keycard-tech/status-keycard)</TableCell>
            <TableCell>The JavaCard applet — key management, BIP-32 derivation, signing, secure channel. This is what runs on the card.</TableCell>
        </TableRow>

        <TableRow>
            <TableCell>[keycard-shell](https://github.com/keycard-tech/keycard-shell)</TableCell>
            <TableCell>Keycard Shell firmware **and** hardware: [schematics + BOM](https://github.com/keycard-tech/keycard-shell/tree/master/hardware/shell/pilot_run/electronics_and_bom) and [3D mechanical files](https://github.com/keycard-tech/keycard-shell/tree/master/hardware/shell/pilot_run/mechanical).</TableCell>
        </TableRow>

        <TableRow>
            <TableCell>[eth-abi-repo](https://github.com/keycard-tech/eth-abi-repo)</TableCell>
            <TableCell>The contract ABI database powering Shell's clear signing. Open to contributions — see [Contribute](/developers/contribute).</TableCell>
        </TableRow>

        <TableRow>
            <TableCell>[keycard-cli](https://github.com/keycard-tech/keycard-cli)</TableCell>
            <TableCell>Command-line tool to install, initialize and manage Keycards with a USB reader.</TableCell>
        </TableRow>
    </TableContent>
</Table>

## Ecosystem projects

A curated list of third-party projects, integrations and experiments built with Keycard is maintained in the [keycard-ecosystem-projects](https://github.com/keycard-tech/keycard-ecosystem-projects) repository.

## Tools

- [Keycard CLI](https://github.com/keycard-tech/keycard-cli) — install and manage applets from the command line
- [Keycard Desktop](https://github.com/choppu/keycard-desktop) — community desktop card manager
- [Keycard Connect](https://github.com/keycard-tech/keycard-connect) — Android app for card initialization and credential management
- Wallets with direct Keycard integration (Status mobile, Status desktop, Sparrow) — see the [full list](/wallets)
